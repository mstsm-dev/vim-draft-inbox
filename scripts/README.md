# 配布スクリプト

vim-draft-inbox 1.0.0 のインストール・アンインストール用スクリプトです。

- `install-windows.cmd` / `uninstall-windows.cmd`: Windows
- `install.sh` / `uninstall.sh`: macOS / Linux

インストール対象:

- `plugin/vim_draft_inbox.vim`
- `doc/vim-draft-inbox.txt`

`tags` ファイルは配布しません。`vim` がPATH上に存在する場合、インストーラーが `helptags` を生成します。
